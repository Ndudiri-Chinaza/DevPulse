# DevPulse

DevPulse is a personal productivity dashboard built with React. It brings GitHub activity, task management, and weather information together in one place.

## Features

- **GitHub Tracker:** Search GitHub usernames to view profile information, recent activity, and repositories.
- **Task Manager:** Add, complete, delete, and filter tasks. Tasks persist across browser refreshes.
- **Weather Widget:** View weather information and search for other cities.
- **Responsive Design:** A dark dashboard interface designed to work across desktop and mobile screens.
- **Accessibility:** Keyboard navigation, visible focus indicators, and reduced-motion support.

## Built With

- React
- Vite
- JavaScript
- CSS
- GitHub API
- Open-Meteo weather API

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository.
2. Open the project directory.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

### Production Build

To create a production build, run:

```bash
npm run build
```
